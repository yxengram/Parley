# Parley Reader

`ParleyReader.html` is a single offline page that opens Parley conversation files (`<UUID>.json`),
plain or encrypted, and shows them read-only the way Parley does. Double-click it to open it in
Safari, Chrome or Firefox, then click **Open…** or drop one or more `.json` files on the window.
Encrypted files ask for their password.

## Privacy

- The page makes no network requests. A Content-Security-Policy in the page blocks any that
  could slip in, all styles, scripts and pictures are inside the file, and it opts out of
  browser page translation.
- Files are read in the browser tab only. Nothing about them is stored. The only saved value is
  the chosen skin and appearance (`localStorage`).
- Decryption uses the browser's Web Crypto, with the same parameters as Parley (PBKDF2-HMAC-SHA256,
  AES-256-GCM, header bound as additional data; see DESIGN.md "Encryption decision"). The password
  is not kept. **Lock** and **Remove from List** drop the decrypted conversation and its pictures.
- Links are never opened directly: a sheet shows the full address first, as in Parley.

## Layout

| File | What |
|---|---|
| `src/core.js` | File parsing and decryption (no DOM) |
| `src/markdown.js` | Port of Parley's `MarkdownParser`, inline parsing and link checks (no DOM) |
| `src/reader.html` | The page: markup, styles, rendering |
| `ParleyReader.html` | Built page (do not edit by hand) |

## Build and test

```sh
tools/build_reader.sh          # writes Reader/ParleyReader.html (art from Resources/Art, downscaled)
tools/test_reader.sh           # fixtures from Parley's own encoder, then the node tests
```

`tools/test_reader.sh` writes fixtures with `swift test --filter writeReaderFixtures`
(`Tests/ParleyCoreTests/ReaderFixtureTests.swift`), then runs `tools/test_reader_core.mjs`
(decryption against those files), `tools/test_reader_markdown.mjs` (parser vectors, including ones
generated by Foundation itself from `tools/reader-tests/oracle.swift`) and
`tools/test_reader_page.mjs` (a static audit of the built page). The build is deterministic.
